Steam **не показывает** JWT в интерфейсе. Но после входа с галочкой **«Запомнить меня»** он сохраняет сессию на диске:

**Файл:** `%LocalAppData%\Steam\local.vdf`  
**Секция:** `ConnectCache`  
**Формат:** зашифровано через Windows DPAPI (расшифровывается только на **твоём** ПК под **твоим** Windows-пользователем).

### Как достать свой токен

**Шаг 1.** Полностью закрой Steam (через трей → Exit).

**Шаг 2.** Узнай **логин** (не ник типа Aurux, а именно login):

- Открой: `C:\Program Files (x86)\Steam\config\loginusers.vdf`
- Найди блок с `"MostRecent" "1"` — там будет `"AccountName"` (это login)
- И `"7656119..."` — это твой SteamID

**Шаг 3.** Расшифровать `ConnectCache` из `local.vdf` — SharpBuy Launcher **умеет только вставлять** токен, **не вытаскивать**. Нужен отдельный скрипт с `CryptUnprotectData`.

**Шаг 4.** Собрать строку:

```text
SteamID----eyJ... (весь JWT)
```
