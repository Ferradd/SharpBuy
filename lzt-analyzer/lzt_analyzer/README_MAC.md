# 🍏 Запуск LZT Smart Analyzer на macOS (MacBook)

Эта папка содержит **полную автономную копию** анализатора со всей базой данных SQLite (`market_cache.db` на 125,000+ лотов), всеми парсерами, связками и новым интерфейсом.

---

## ⚡ Как запустить на MacBook:

### Вариант 1: Через Терминал (Рекомендуется)
1. Откройте приложение **Терминал** (Terminal).
2. Перейдите в папку проекта (или просто напишите `cd ` и перетащите папку `lzt_analyzer` мышкой в окно терминала):
   ```bash
   cd ~/Downloads/lzt_analyzer   # или путь куда вы скопировали папку
   ```
3. Сделайте скрипт исполняемым и запустите:
   ```bash
   chmod +x start_mac.sh
   ./start_mac.sh
   ```
4. Браузер сам откроет **[http://localhost:8080](http://localhost:8080)**!

---

### Вариант 2: В один клик
1. В первый раз откройте Терминал и выполните один раз:
   ```bash
   chmod +x /путь_к_папке/lzt_analyzer/start_mac.command
   ```
2. После этого `start_mac.command` можно запускать двойным кликом прямо из Finder!

---

## 📦 Необходимые требования:
- Установленный Python 3 (на macOS обычно уже есть, либо ставится через `brew install python` или с [python.org](https://www.python.org/downloads/)).
- Библиотека `requests` (скрипт установит её автоматически при первом запуске через `pip install requests`).

---

## 🛑 Как остановить:
- В окне Терминала нажмите `Ctrl + C`.
